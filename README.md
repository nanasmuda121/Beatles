# Beatles (NanzBeatles)

A modern, elegant Android music streaming and player app powered by Jetpack Compose and Media3.

## Features
- **Liquid Glass Design**: Modern widgets and translucent glassy UI elements.
- **Synced Lyrics**: Word-by-word synced lyrics with translation, Apple Music style typography, and fluid blur effects.
- **Advanced Audio Engine**: Reverb, dynamic audio processor, and high-fidelity playback.
- **Multi-variant Support**: FOSS, GMS (Google Cast), Standalone architecture builds, and Android TV.
- **Rich Presence**: Discord Rich Presence support.

## Building

Building release APK:
```bash
./gradlew assembleFossMobileUniversalRelease
```
